Autonomous & Remote-Controlled Racing Car

A hybrid racing car built with our team, operating in two modes: manual wireless control and autonomous obstacle-avoidance driving. Built around an ESP32 microcontroller for its processing power and integrated connectivity, programmed in Arduino C/C++. Aug 2026 / ATmega32 · Bare-Metal C

Bare-Metal Chrome Dinosaur Game on ATmega32

A complete rebuild of the Chrome dinosaur game, built entirely in C at the bare-metal level with zero vendor libraries, validated through both Proteus simulation and real hardware. We structured the code into layered MCAL / HAL / Application layers, and built our own drivers from scratch — including a DIO driver and a 4-bit 16×2 LCD driver. Character sprites (the dinosaur's run animation, cacti, and birds) were designed pixel-by-pixel using CGRAM. Game logic runs as a non-blocking loop driven by a millisecond timer, handling jump mechanics, button debouncing, and collision detection — with speed that accelerates automatically as the score increases.

  • 100%Bare-metal — zero vendor libraries
  • CGRAMCustom pixel-by-pixel sprites
